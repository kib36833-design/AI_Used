# 上海地鐵立體路網

`index.html` 是上海地鐵 3D 路線分布圖，也能查路線（單一頁面，需連網載入 three.js）。

- **3D 路網**：21 條營運路線（1–18 號線、浦江線、機場聯絡線、磁浮線），共 412 座車站。「立體分層」模式把每條路線放在不同高度，轉乘站以立柱連接；也可切換成「平面路網」或「俯視」。
- **路線查詢**：可輸入起訖站（繁體、簡體或地標，例如「外灘」「PVG」「新天地」），也可直接在 3D 圖上點選車站。結果會列出上車站、每段的路線與行車方向、轉乘站和下車站，並提供「最快」「最少轉乘」「只搭一般地鐵」三種方案。
- **常用路線**：機場→市區、市區→迪士尼等，點一下就能查。

## 資料

站點資料在 `tools/build_data.py`，執行後會產生 `metro-data.js`：

```bash
pip install opencc-python-reimplemented
python3 tools/build_data.py
```

站序依 2025 年底營運路網整理。車站座標是示意用的近似值；行車時間依站距和平均時速估算，每次轉乘另加 5 分鐘。票價只估算一般地鐵的里程票價，磁浮與機場聯絡線另計。實際搭乘請以上海地鐵官方資訊為準。
