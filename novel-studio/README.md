# 小說影視化工坊 v3（新增 MV 製作）

董元創作室的小說改編工具：匯入小說 → 劇情拆解 → 設定卡 → 分鏡 → 提示詞 → 出片模式 → 對白與聲音 → 匯出。
v3 依《第四十七趟》行銷 MV《後座》企劃書的結構，新增「MV 音樂錄影帶」產出類型。

### GAS 版更新步驟

1. 打開原本的 Apps Script 專案。
2. 用 `gas/Code.gs` 取代 `Code.gs`、用 `gas/Index.html` 取代 `Index.html`，存檔。
3. 「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」。網址不變，舊作品照常開啟。

## MV 製作功能

在「匯入小說 → 專案設定 → 產出類型」選 **MV 音樂錄影帶（行銷 MV）**，左側流程變成：

匯入小說 → **MV 企劃** → **段落拆解** → 設定卡 → 分鏡 → 提示詞 → 出片模式 → **歌曲與聲音** → 匯出

### MV 企劃頁（對應企劃書七大段）

| 區塊 | 內容 |
|---|---|
| 一、MV 總企劃 | 曲名、片長、曲風、畫面風格、宣傳金句、核心概念、雙層觀看設計（路人／讀者）、不劇透原則、情緒與節奏曲線、淚點地圖 |
| 二、歌曲企劃 | 速度、調性、主唱、長度、漸進式編曲層次、Suno Style of Music／Exclude Styles |
| 三、歌詞 | 可直接貼進 Suno Lyrics 欄的歌詞與設計重點 |
| 四、分鏡腳本 | 段落數、分鏡數、目前總長與目標片長的差距；讀者彩蛋清單 |
| 五、BGM 企劃 | 純音樂版、片尾 cue（逐行「時間｜設計」）、Suno 提示詞、靜默段音效 |
| 六、片尾文字 | 詞＋問句、金句、書名 |

- **AI 生成 MV 企劃**：依原文、設定卡、目標片長、歌曲視角與補充要求，一次產出上面全部欄位。
- **載入範例《後座》**：把《第四十七趟》的 MV 企劃載入當範本，可直接修改。
- 每張表格都能逐格編輯、新增、刪除列。

### MV 專屬行為

- **段落拆解**：依情緒曲線把歌曲切成前奏、主歌、副歌、橋段…，段落數預設等於情緒曲線的段數。
- **時間碼**：依段落順序與每鏡時長自動累計（例如 `2:10–2:15`），顯示在膠卷、鏡頭卡、提示詞、出片模式，並寫進 CSV、TXT。時長可填任意整數秒。
- **歌詞不對嘴**：對白欄角色寫「主唱（女聲）」或語氣寫「歌詞」的行視為歌詞。影片提示詞會註明人物不對嘴，音軌提示詞把歌詞列為 Suno 歌曲、不另配音。
- **字卡**：「畫面文字／字卡」欄在 MV 模式一律顯示；出片平台選 Omni 時直接渲染進畫面，其他平台列入字卡清單後製。
- **分鏡指令**：自動帶入 MV 企劃（不劇透原則、淚點、彩蛋、歌詞）與前一段結束時間。

### MV 匯出

| 匯出 | 內容 |
|---|---|
| MV 企劃書（.md） | 與《後座》企劃書同格式，含 S01、S02… 全片分鏡表 |
| Suno 歌詞與風格（.txt） | Style of Music、Exclude Styles、歌詞、BGM 提示詞 |
| 字卡清單（.txt） | 依時間碼列出所有字卡，加上片尾問句與金句 |

GAS 版的匯出檔存到雲端硬碟「小說影視化工坊／匯出檔」。

## 相容舊資料

- v2 的 JSON 備份與「第四十七趟MV_後座_匯入」這類匯入檔可直接讀入；讀入後把產出類型改成 MV 即可。
- 非標準時長（例如 5 秒）會原樣保留，不再被改成 8 秒。
- 切回 AI 短劇或漫畫時，MV 企劃資料會保留，畫面與流程恢復原樣。
