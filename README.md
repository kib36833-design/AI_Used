# 旅遊萬用平台（國內外通用）

把原本兩支獨立工具整合成**單一 HTML 檔**的萬用平台：

| 原始工具 | 整合後位置 |
|---|---|
| 行程資料 AI 轉換器（照片／PDF／文字 → JSON） | 分頁「🤖 AI 建立行程」，解析完可**直接建立旅程**，不必再下載 JSON 手動匯入 |
| 領隊控制台（籌備／每日行程／費用／報告） | 分頁「🧳 籌備」「Day N」「📋 報告產出」「⚙ 設定」 |

檔案：`index.html`（單檔、離線可用、無外部相依）。

## 新增的整合能力

### 1. 國內／國外雙模式
每個旅程都有「旅遊型態」：

- **🏠 國內旅遊**：全程台幣單一幣別。自動隱藏匯率欄與幣別選單，費用與籌備表格少一欄，報告以台幣單一金額呈現。
- **✈️ 國外旅遊**：當地幣＋台幣雙幣別，可設匯率，所有合計自動折合台幣。

在「⚙ 設定」可隨時切換；由**國外改成國內**時，既有的當地幣紀錄會依當時匯率換算成台幣後保存，金額不會失真。

### 2. 多旅程並存（🗂 旅程）
不再是「一次只能一趟」。可建立、切換、複製（複製行程架構、不含紀錄，適合重複帶同一條線）、單獨匯出、刪除；每張卡片顯示天數、完成率與總經費。

### 3. AI 建立行程 → 一鍵成案
上傳行程表照片／PDF 或貼上文字，AI 解析後可選：

- **建立為新旅程**（保留現有旅程）
- **覆蓋目前旅程的行程內容**（費用與籌備紀錄保留，勾選紀錄清除）
- **下載 JSON 匯入檔**（給其他裝置用）

AI 會一併判斷這趟是國內還是國外，自動帶入幣別。

### 4. ✍ 文字快速建立（離線可用）
AI 解析需要在 Claude 對話視窗中開啟才能連線。離線時改按「文字快速建立」，直接在瀏覽器就地拆解貼上的行程文字：辨識 `Day1`／`第1天`／日期開頭分天，抓出 `07:00`、`0830`、`午餐` 等時間標籤，`住宿：` 開頭自動填入住宿欄。

### 5. 相容舊資料
- 舊版「領隊控制台」的 localStorage 紀錄，第一次開啟本平台時**自動承接**成第一個旅程（勾選、備註、費用、籌備全部保留）。
- 「📂 匯入備份」相容三種檔案：本平台全備份、單一旅程檔、舊版控制台／AI 轉換器產出的 JSON。匯入時可選擇「取代全部」或「加入清單」。
- 舊資料的 `RMB` 幣別欄自動轉為通用的「當地幣（LOC）」。

## 使用方式

1. 用瀏覽器開啟 `index.html`（電腦或手機皆可）。
2. 手機：瀏覽器選單 →「加入主畫面」，即成為全螢幕 App。
3. 資料存在該裝置瀏覽器的本機儲存區，**手機與電腦不互通**；換裝置前先「💾 匯出備份」，到新裝置「📂 匯入備份」。

## 報告產出

「📋 報告產出」可預覽**當日報告**或**全程總報告**，再匯出 Word（.doc）或 PDF（列印 → 另存為 PDF）。報告包含：行程完成紀錄與完成時間、未執行項目、行程變數備註（自動抓出備註內的時間點）、籌備支出分類明細、每日費用與全程經費總計。

## 驗證

以 Playwright（Chromium）跑過 19 項端對端測試：預設載入、勾選計時、國內／國外費用與折合、籌備合計、報告金額、離線文字解析、AI 失敗指引、建立／覆蓋旅程、複製刪除、備份匯出匯入、舊版相容、Word 匯出、重新載入後持久化，以及手機與桌面版面無水平溢出。

## 線上版（手機直接開網址）

在 GitHub 上啟用一次 Pages 即可（只需做一次）：

**Settings → Pages → Build and deployment → Source 選「Deploy from a branch」→ Branch 選 `main` / `(root)` → Save**

約 1 分鐘後網站上線：<https://kib36833-design.github.io/AI_Used/>

之後只要 `main` 有更新，GitHub 會自動重新發佈。手機用瀏覽器開啟後選「加入主畫面」即成為 App。資料存在該裝置瀏覽器的本機儲存區（各裝置獨立），換機時用「💾 匯出備份 → 📂 匯入備份」搬移。
